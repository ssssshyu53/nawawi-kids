# دليل الوحدات — Modules Guide

## خريطة الرحلة (Journey Map)
- `renderMap()` في `kids.js` يرسم الفصول الأربعة، ولكل فصل مسار SVG متعرّج (طبقة حدود + طبقة طريق + خط متقطع للمتبقي أو خط ملوّن للمنجز).
- إحداثيات المحطة: `x = W/2 + wave[(id-1) % 8] * amp` و `y = TOP + i * GAP` حيث `GAP = 168` لمنع تداخل التسميات مع فقاعة «محطتك التالية!».
- حالات المحطة: `is-locked` (قفل)، `is-open` (رقم)، `is-current` (نابضة مع فقاعة)، `is-done` (نجمة ذهبية)، `is-just-earned` (حركة احتفال).
- يُعاد الرسم عند تغيير عرض النافذة (مع تأخير 180ms).

## المحطة (Station)
- `selectHadith(id)` يجهّز كل الخطوات الأربع ويضبط عدّاد «الفصل … — المحطة n من ٤٢».
- `switchTab(step)` يبدّل الخطوة، يضع علامة إنجاز على الخطوات التي زارها الطفل، ويغيّر رسالة المرشد باسم الطفل.

## المشغّل الصوتي والمزامنة
- `updateSyncHighlight()` يعمل عبر `requestAnimationFrame` ويبحث ثنائياً عن الكلمة الحالية في `words[]`، مع تثبيت قصير (0.35s) في الفواصل بين الكلمات.
- النقر على كلمة: إن كانت البيانات الوصفية جاهزة يقفز مباشرة، وإلا يخزن `pendingSeekTime` ويطبّقه عند `loadedmetadata` أو `canplay`.
- السرعات: ١x / ٠.٧٥x / ١.١٥x. التكرار: لا / ٣ مرات / دائم.

## الحفظ
- `computeHiddenWords()` يختار الكلمات المخفية بخلط حتمي مبذور بـ (رقم الحديث + بذرة + النسبة) ليبقى النمط ثابتاً حتى يطلب الطفل «غيّر الكلمات المخفية».
- التسجيل بـ `MediaRecorder` (حد أقصى 3 دقائق)، وبعد الإيقاف يُكشف النص كاملاً للمقارنة.

## التدريبات وفتح المحطات
- 3 أسئلة لكل حديث؛ الإجابة الخاطئة تعطّل الخيار وتعطي تلميحاً، والصحيحة تقفل السؤال.
- عند إكمال الثلاثة: `markHadithCompleted()` يضيف النجمة، يرفع `unlockedUpTo`، ويعرض لافتة الاحتفال.

## الشهادة
- `certificate.php?name=…&date=…[&download=1]` يرسم الاسم (Cairo) والتاريخ والتوقيع (Amiri) على القالب.
- التشكيل العربي: `ArPHP` إن توفّرت، وإلا `lib/ArabicGlyphs.php` مع عكس ترتيب الكلمات.
- تُفتح الشهادة بعد ٤٢ نجمة أو في وضع المعلم.

## المؤثرات الصوتية
- `playSfx()` يولّد نغمات قصيرة عبر WebAudio (بدون ملفات)، ويمكن كتمها من زر الصوت في الترويسة.
